# 📊 PhonePe Transaction Analytics Dashboard

An interactive Power BI dashboard designed to analyze PhonePe transaction
performance across multiple financial services including Loans, Insurance,
Money Transfer, and Bills & Recharge.

## 🚀 Project Overview

This project transforms transaction-level data into an interactive business
intelligence dashboard using Microsoft Power BI.

The dashboard analyzes:

- Total transaction volume
- Total transaction amount
- Successful vs failed transactions
- Failed payment reasons
- Category-wise performance
- Monthly transaction trends
- Service-level performance

## 📌 Dashboard Pages

### 🏠 Home

Provides an overall view of PhonePe transaction performance.

Key metrics include:

- Total transactions

- Failed transactions

- Service-wise analysis

## 📊 Key Insights

- The majority of transactions are successful.
- Failed transactions represent a relatively small percentage of overall
  transaction volume.
- Payment failures occur due to several reasons including server errors,
  incorrect PINs, insufficient amounts, and incorrect information.
- Transaction values vary across financial services and transaction
  categories.
- Monthly trends provide visibility into changes in transaction activity
  throughout the year.
