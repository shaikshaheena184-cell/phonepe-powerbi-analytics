# Data Dictionary

## Transaction Fields

| Field | Description |
|---|---|
| Transaction_ID | Unique identifier for each transaction |
| User_ID | Identifier associated with the user |
| Date | Transaction date |
| Amount | Monetary value of the transaction |
| Payment_Status | Indicates whether the transaction was successful or failed |
| Reason | Reason associated with a failed payment |
| Transaction_Type | Category/type of transaction |
| Recharge_Type | Bill or recharge category where applicable |

## Main Transaction Categories

- Loans
- Insurance
- Money Transfer
- Bills & Recharge
