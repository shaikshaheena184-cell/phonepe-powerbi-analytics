# Project Notes

## Data Preparation

The transaction dataset was imported into Power BI and prepared for analysis.

Key preparation activities included:

- Checking data types
- Validating transaction dates
- Checking transaction amounts
- Reviewing payment status
- Analyzing failed payment reasons
- Creating appropriate aggregations

## Data Modeling

Transaction data was organized into service-level datasets for analysis.

## Dashboard Development

The report was designed using:

- KPI cards
- Donut charts
- Bar charts
- Monthly trend charts
- Date filters
- Interactive navigation

## Validation

Dashboard metrics were cross-checked against the source Excel data to
ensure consistency between the source data and Power BI visualizations.
